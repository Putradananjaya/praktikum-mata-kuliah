Dasar Pemrograman Python: Variabel, Tipe Data, dan Masukan-Keluaran

Memilih tipe data untuk data bisnis, melengkapi program perhitungan sederhana, dan menemukan penyebab kesalahan pada program Python. Bacalah halaman ini sampai habis sebelum mulai.

1. Masalah

Program yang berjalan tanpa pesan kesalahan belum tentu benar. Menjumlahkan dua hasil input() tanpa konversi menghasilkan 100200, bukan 300. Angkanya tampak wajar, tidak ada pesan kesalahan, dan program berjalan mulus sampai akhir.

Nomor telepon yang disimpan sebagai bilangan kehilangan angka nol di depannya: 081234567890 berubah menjadi 81234567890. Kekeliruan semacam ini baru ketahuan setelah ratusan data pelanggan telanjur tersimpan.

Pertanyaannya: bagaimana memilih tipe data yang tepat untuk setiap data bisnis, dan bagaimana membaca pesan kesalahan Python untuk menemukan penyebabnya dengan cepat?

2. Tujuan Praktikum

Setelah praktikum ini Anda diharapkan mampu:

  1. Memilih tipe data yang tepat untuk berbagai data bisnis beserta alasannya.
  2. Melengkapi program perhitungan bisnis dengan konversi tipe dan pemformatan rupiah yang benar.
  3. Menemukan jenis, letak, dan perbaikan kesalahan pada program Python yang bermasalah.

3. Manfaat

  • Bekal untuk Pertemuan 9–15. Seluruh program pada pertemuan berikutnya bertumpu pada variabel, tipe data, dan masukan-keluaran.
  • Bersambung ke mata kuliah lanjutan. Python dipakai pada Analitik Bisnis, Business Intelligence, dan Sains Data.
  • Mencegah kerusakan data. Pemilihan tipe yang keliru merusak data pelanggan secara diam-diam, tanpa pesan kesalahan apa pun.
  • Membaca pesan kesalahan, bukan menebak. Anda belajar menemukan baris penyebab dari pesan yang ditampilkan Python.

Anda membangun sistem kasir sederhana untuk Toko Kopi Nusantara. Data produk, harga, dan pelanggan harus disimpan dengan tipe yang tepat, lalu diolah menjadi tagihan yang terbaca rapi. Beberapa program yang sudah ditulis rekan Anda bermasalah dan harus diperbaiki.

5. Konsep yang Perlu Dipahami

Padanan pseudocode ke Python

BACA → input(), TETAPKAN dan HITUNG → =, TAMPILKAN → print(). MULAI dan SELESAI tidak punya padanan; program Python berjalan dari baris pertama sampai baris terakhir.

Makna tanda =

Tanda = bukan berarti "sama dengan", melainkan perintah memberi nilai: hitung ruas kanan, lalu simpan hasilnya ke nama di ruas kiri. Karena itu x = x + 1 masuk akal dalam Python.

Empat tipe data dasar

int (bilangan bulat), float (bilangan berkoma), str (teks), dan bool (benar atau salah). Python menetapkan tipe secara otomatis dari nilai yang diberikan.

Kaidah input()

input() selalu menghasilkan teks, tanpa pengecualian. Masukan berupa angka wajib dikonversi dengan int() atau float() sebelum dihitung.

PenulisanHasilKeterangan

Cara membaca pesan kesalahan: lihat baris terakhirnya untuk jenis dan penjelasan kesalahan, lalu lihat line N untuk nomor barisnya.

Kesalahan logika, misalnya lupa huruf f atau menjumlahkan dua teks, tidak memicu pesan apa pun. Program berjalan sampai selesai, tetapi hasilnya keliru. Hanya pembandingan dengan perhitungan manual yang dapat mengungkapnya.
