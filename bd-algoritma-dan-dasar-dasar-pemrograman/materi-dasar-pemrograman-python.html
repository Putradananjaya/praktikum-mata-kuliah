Kenalan dengan PAMN

PAMN adalah robot humanoid dari negeri petualangan kuno yang kini menjaga Toko Kopi Nusantara. Di halaman ini PAMN mewakili Python: ia sangat rajin tetapi sangat harfiah, menjalankan perintah baris demi baris, dari atas ke bawah, persis seperti tertulis. PAMN tidak pernah menebak maksud Anda.

Di gudang PAMN, setiap tipe data punya wadahnya sendiri: kepeng emas untuk int, botol ramuan untuk float, gulungan perkamen untuk str, dan lentera untuk bool.

Bila perintahnya keliru sedikit saja, misalnya huruf besar yang tertukar atau tanda kutip yang lupa ditutup, PAMN berhenti dan menampilkan pesan kesalahan. Bab 7 mengajarkan cara membaca pesan tersebut.

Bab 1

Dari Pseudocode ke Python

Pada Modul 5, algoritma ditulis dalam pseudocode: bahasa yang mudah dibaca manusia, tetapi tidak dapat dijalankan komputer. Agar dapat dijalankan, algoritma ditulis ulang dalam bahasa pemrograman. Mata kuliah ini memakai Python, bahasa yang ringkas, mudah dibaca, dan banyak dipakai di bidang analitik bisnis.

Program Python adalah kumpulan perintah. Setiap baris berisi satu perintah, dan Python menjalankannya dari baris pertama sampai baris terakhir.

Aturan Menulis Python

  • Huruf besar dan kecil dibedakan. print benar, Print keliru. harga dan Harga adalah dua nama yang berbeda.

  • Baris tidak boleh diawali spasi sembarangan. Spasi di awal baris punya arti khusus dalam Python, yang akan dipelajari pada pertemuan percabangan.

Bab 2

Variabel: Kotak Berlabel

Variabel adalah tempat menyimpan nilai, seperti kotak berlabel di rak gudang. Labelnya adalah nama variabel, isinya adalah nilai. Setiap kali nama itu dipakai, Python mengambil isi kotaknya.

Makna Tanda =

Dalam Python, tanda = bukan berarti "sama dengan". Tanda = adalah perintah: hitung ruas kanan, lalu masukkan hasilnya ke kotak di ruas kiri. Bacalah total = harga * jumlah sebagai "total diisi dengan harga dikali jumlah".

  • Ruas kanan dihitung lebih dahulu, baru hasilnya disimpan.
  • Satu kotak hanya menyimpan satu nilai. Bila diisi lagi, nilai lama dibuang.
  • Variabel menyimpan nilai, bukan rumus. Bila harga berubah, total tidak ikut berubah sampai baris total = … dijalankan lagi.

Telusuri program berikut dengan tombol Langkah ▶. Perhatikan gudang di kanan: PAMN berjalan ke peti yang diisi, mengganti isinya, dan membuang nilai lama.

Mengganti Isi Variabel

Pada contoh kedua, total tetap 90000 meskipun harga sudah diganti menjadi 50000. Variabel menyimpan hasil hitungan pada saat baris itu dijalankan.

Pola x = x + 1: Penampung dan Pencacah

Dalam matematika, x = x + 1 mustahil. Dalam Python, artinya jelas: ambil isi x sekarang, tambah 1, lalu simpan kembali ke x. Pola ini dipakai untuk menghitung banyaknya sesuatu (pencacah) dan menjumlahkan nilai (penampung) pada Pertemuan 11.

Python juga menyediakan bentuk singkat: stok -= 5 sama dengan stok = stok - 5, dan stok += 12 sama dengan stok = stok + 12.

Kaidah penamaan yang baik

  • Jelaskan isinya: total_belanja, bukan x atau tb.
  • Huruf kecil, antarkata dipisah garis bawah (snake_case): harga_satuan, bukan hargaSatuan.
  • Jangan memakai nama fungsi bawaan seperti print atau input. Python tidak menolaknya, tetapi setelah ditimpa, fungsinya tidak dapat dipakai lagi.

Permainan: Stempel Label

Label nama variabel datang satu per satu. Stempel SAH atau TIDAK SAH sebelum waktunya habis. Papan ketik: S untuk sah, T untuk tidak sah.

Bab 3

Empat Tipe Data Dasar

Setiap nilai dalam Python punya tipe. Tipe menentukan apa yang dapat dilakukan terhadap nilai itu: bilangan dapat dihitung, teks dapat disambung. Di halaman ini setiap tipe punya warna dan gambar yang tetap.

Python Menentukan Tipe Secara Otomatis

Anda tidak perlu menyebutkan tipe. Python melihat cara nilai ditulis: tanpa titik berarti int, dengan titik desimal berarti float, diapit tanda kutip berarti str, dan True/False berarti bool. Fungsi type() menunjukkan tipe sebuah nilai.

Tanda kutip mengubah segalanya

45000 dan "45000" tampak sama, tetapi yang pertama bilangan dan yang kedua teks. Akibatnya berbeda ketika dioperasikan.

Mengapa Nomor Telepon Disimpan sebagai Teks?

Perhatikan apa yang terjadi bila nomor telepon diubah menjadi bilangan dengan int().

Bilangan tidak mengenal angka nol di depan, jadi 081234567890 berubah menjadi 81234567890. Menulis 081234567890 tanpa tanda kutip di dalam kode bahkan ditolak Python dengan SyntaxError.

Uji sederhana: apakah nilai ini akan pernah dijumlahkan, dikurangi, atau dikalikan? Bila tidak, simpan sebagai teks. Nomor telepon, NIM, kode pos, dan nomor rekening tidak pernah dihitung.

Tipe bool dan Perbandingan

bool hanya punya dua nilai: True dan False, dengan huruf awal kapital. Nilai bool biasanya lahir dari perbandingan.

Bab 4

Operator Aritmetika

Operator adalah tanda untuk mengolah nilai. Hasil pengolahan disebut ekspresi, dan ekspresi selalu menghasilkan satu nilai.

OperatorArtiContohHasil
+tambah17 + 522
-kurang17 - 512
*kali17 * 585
/bagi (hasilnya selalu float)17 / 53.4
//bagi bulat (sisa dibuang)17 // 53
%sisa pembagian17 % 52
**pangkat17 ** 2289
Pembagian dengan / selalu menghasilkan float, sekalipun hasilnya bulat: 100 / 4 menghasilkan 25.0, bukan 25.

Urutan Pengerjaan

Sama seperti matematika: kurung lebih dahulu, lalu **, lalu * / // %, terakhir + -. Bila ragu, pakailah kurung.

Program di atas menghitung harga 3 barang yang masing-masing mendapat potongan 10.000. Tanpa kurung, potongan dikalikan lebih dahulu sehingga hasilnya keliru.

Persen dalam Python

Tanda % dalam Python bukan persen, melainkan sisa pembagian. Untuk menghitung 11% dari suatu nilai, tulis * 11 / 100 atau * 0.11.

Perhatikan baris ketiga: harga ditambah pajak 11% sekaligus (* 1.11) menghasilkan 49950.00000000001, bukan 49950.0. Bilangan berkoma disimpan komputer dalam bentuk biner sehingga kadang muncul selisih sangat kecil. Selisih ini wajar; cara merapikan tampilannya dibahas di Bab 6.

Operator pada Teks

Tanda + pada dua teks menyambung, dan tanda * antara teks dan bilangan bulat mengulang. Tanda - dan / tidak berlaku untuk teks.

input(): PAMN Bertanya, Pengguna Mengetik

    
input() menampilkan pertanyaan, menunggu pengguna mengetik, lalu mengembalikan ketikan itu. Hasilnya selalu teks (str), sekalipun yang diketik berupa angka. Inilah sumber kesalahan paling umum bagi pemula.

    

  

  

    
Konversi Tipe

    
Teks hasil input() diubah menjadi bilangan dengan fungsi konversi.

    

      
FungsiMengubah menjadiContoh berhasilContoh gagal

      
int()bilangan bulatint("45000") → 45000int("12.5"), int("45.000") → ValueError

      
float()bilangan berkomafloat("12.5") → 12.5float("12,5") → ValueError

      
str()teksstr(45000) → '45000'Selalu berhasil

    

    

    
Perhatikan baris terakhir: int(12.9) menghasilkan 12. Bagian di belakang koma dibuang, bukan dibulatkan.

Bacalah dari dalam ke luar. Ketiga langkah ini terjadi dalam satu baris:

② int( … )Teks diubah menjadi bilangan bulat 45000.

      
③ harga = …Bilangan disimpan ke kotak harga.

    

    
Telusuri program kasir berikut. Ubah juga isi ketikan pengguna, misalnya menjadi 12.5 atau 45.000, lalu jalankan ulang.

Bab 6

    
print(): Menampilkan ke Layar

    
print() menampilkan nilai ke layar, lalu pindah ke baris baru. Beberapa nilai yang dipisah koma ditampilkan berurutan dengan satu spasi di antaranya.

    

  

  

    
Menggabungkan Teks dan Angka

    
Tanda + tidak dapat menyambung teks dengan bilangan.

    

    
Ada tiga cara yang benar: pisahkan dengan koma, ubah bilangan menjadi teks dengan str(), atau gunakan f-string.

    

  

  

    
f-string: Teks Berlubang

    
f-string adalah teks yang diawali huruf f. Setiap { } di dalamnya adalah lubang yang diisi nilai. Di dalam lubang boleh ditulis nama variabel maupun perhitungan.

    

    
Tanpa huruf f, kurung kurawal dicetak apa adanya. Python tidak menampilkan pesan kesalahan apa pun.

    

  

  

    
Format Rupiah dan Desimal

    
Tanda titik dua di dalam lubang mengatur tampilan angka.

    

      
PenulisanHasilKeterangan

f"Rp{total:,}".replace(",", ".")Rp1.250.000Format Indonesia: koma diganti titik
